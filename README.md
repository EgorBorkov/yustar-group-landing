# PHP-обработчик: технический пример

Здесь сохранён пример серверной части проекта: валидация формы на PHP, защита от простого спама и отправка через PHPMailer/SMTP. Код перенесён из отдельной подготовленной к запуску сборки.

Папка **не участвует** в демонстрации на GitHub Pages. GitHub Pages не исполняет PHP, поэтому публичная демо-форма работает только в браузере и не отправляет данные.

Для реального развёртывания нужен отдельный PHP-хостинг, проверенные юридические условия обработки данных и конфигурация за пределами публичного каталога. Файл config.php.example — пустой шаблон; **никогда не публикуйте заполненный config.php**.

Продакшен-сайт заказчика уже работает отдельно. **Этот репозиторий не используется для его обновления.**
