# ЮСТАР ГРУПП — корпоративный лендинг

Реализованный веб-проект для ООО «ЮСТАР ГРУПП»: одностраничный сайт инженерной компании, работающей с технологиями очистных сооружений и обезвоживания осадка.

**Статус:** проект принят заказчиком и передан на его хостинг.

**Моя роль:** структура и разработка сайта, адаптивная вёрстка, интерактивные элементы, серверная обработка формы, тестирование и запуск. [Профиль разработчика на GitHub](https://github.com/EgorBorkov).

> **Портфолио-демонстрация.** Эта копия не связана с рабочей почтой заказчика. Форма проверяет поля в браузере, но **не отправляет и не сохраняет** введённые данные. Изображения писем и сертификатов заменены нейтральными макетами: оригиналы не распространяются через Git.

## Что сделано

- Адаптивная компоновка для смартфонов и настольных экранов.
- Меню для мобильных устройств, закреплённая шапка, навигация по разделам и кнопка «Наверх».
- Блоки технологии, этапов внедрения и кейсов.
- Просмотр документов в модальном окне с управлением клавиатурой.
- Валидация имени, телефона/e-mail и обязательного подтверждения согласия.
- Семантическая HTML-разметка, SEO-метатеги, WebP, отложенная загрузка изображений.
- В рабочей версии — PHP-обработчик с PHPMailer и защищённым SMTP, ограничением частоты запросов и хранением технических сведений вне публичного каталога.

## Стек

HTML5 · CSS3 · JavaScript · PHP · PHPMailer · SMTP · Git

Без CMS и фронтенд-фреймворка. Дизайн и интерфейсы реализованы на нативных технологиях.

## Демо и структура

Статическую демоверсию можно открыть локально:

    cd docs
    python3 -m http.server 8000

Затем перейти на http://localhost:8000. Все ссылки внутри демо относительные — проект пригоден и для размещения в подпапке GitHub Pages.

    docs/                   # Статическая версия для GitHub Pages
      index.html             # Главная
      privacy.html           # Архивный пример юридической страницы
      consent.html           # Архивный пример согласия
      css/                   # Стили
      js/                    # Поведение интерфейса и клиентская валидация
      assets/                # Изображения и нейтральные заглушки документов
    backend/                # Пример серверного обработчика, не выполняется на Pages
      api/contact.php
      private/               # Пустой шаблон SMTP и composer.json

### Подключение GitHub Pages

После публикации репозитория выберите **Settings → Pages → Deploy from a branch → main → /docs**. GitHub Pages покажет только статическое демо; PHP-часть остаётся в репозитории как пример кода.

## Безопасность и права

- В репозитории **нет** SMTP-паролей, заполненных конфигов, учётных данных хостинга, квитанций согласия посетителей и серверных журналов.
- Письма, сертификаты и прочие материалы заказчика не включены в демо: вместо них подготовлены нейтральные SVG.
- Логотип, фирменное название, тексты и фотографии могут принадлежать заказчику или третьим лицам. **Публичная публикация репозитория и использование материалов для портфолио требуют разрешения правообладателей.** До этого храните репозиторий приватным.
- Лицензия на повторное использование кода **не предоставляется**.
